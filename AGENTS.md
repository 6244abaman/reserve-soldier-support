# Repository instructions

Read CLAUDE.md for product rules and APP-OPERATIONS.md for the shared delivery
workflow before changing the app. Preserve both. Use app-deployment.json for
the confirmed existing service/workspace identities, and HOSTING.txt for the
owner's dashboard, opening and update steps.

Routine requested updates include tested GitHub changes and verification of
the existing Render app at the same public URL, unless the current request
explicitly asks for local-only or draft-only work. Do not create new paid
services or replace the established app URL merely to publish an update.
